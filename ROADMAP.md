# Roadmap

> **Maintenance status**: This plugin depends on DeepSeek Harness (dsh), which is currently in developer preview and evolves rapidly with potentially breaking changes. This project is therefore **paused for active maintenance** and may not work on the latest dsh. The roadmap below reflects the current feature state; development resumes once the dsh repository stabilizes.

Planned and completed capabilities for dsh-invoke, grouped by priority (P0 → P2).

| Priority | Module                                       | Status             |
| -------- | -------------------------------------------- | ------------------ |
| P0       | Core CRUD (add/edit/delete/query)            | Done               |
| P0       | Copy to clipboard + variable fill            | Done               |
| P0       | Category tree management & live search       | Done               |
| P0       | Light/dark theme auto-adaptation             | Done               |
| P1       | Import / export                              | Done (JSON / YAML) |
